# Cloud Extension Manager

Open `/prototype/homestead?v=2&flow=extensions`, or add `&scenario=first` to start as a new Cloud user without a custom environment. This opt-in journey starts in Cloud with a compatible workflow and a large modal for browsing and selecting node packs over the real editor. Search names, publishers and descriptions, or switch between all packs, installed packs and available updates. Compact rows show descriptions, installed versions and pending selections. A checkbox includes each pack in the desired environment; installed packs start checked, and unchecking stages removal. Choose versions separately. Pages contain five packs by default; selections persist across page changes, filters and searches. Homestead V1–V3 journeys remain available without `flow=extensions`.

Choose versions to add or update installed packs; removing a pack is an explicit reviewed change and never deletes graph nodes. **Add your own** appears above the catalog. Add a GitHub repository URL, or select a local ZIP through drag-and-drop or the file picker. The prototype validates the ZIP filename and records metadata only; it never reads or uploads archive contents. Close and reopen the manager to retain selections within the current page session.

**Review changes** defaults to updating the current shared environment when a custom environment exists. First-time Cloud users create a new custom environment within the same modal; models and GPU settings are suggested from workflow models and remain editable. **Create a new environment** inherits editable packs, models, GPU and storage settings. Review stays in the modal before any preparation starts. It shows illustrative GPU rates of $0.0012/second for A100 or $0.0006/second for L40S, plus $0.07/GB-month storage. These sample rates are not quotes or authoritative billing inputs.

**Prepare environment** closes the modal and opens a dismissible status side panel, returning focus to the workflow canvas. Keep editing and submitting Run jobs on the working revision. Reopen progress through the persistent status indicator. Readiness and its email preview never authorize a switch: explicitly choose **Approve and apply environment**. Approval pauses new submissions for everyone on the shared target; accepted running and queued jobs finish on the old revision before it switches. Unrelated environments stay runnable. The canvas, unsaved inputs and outputs remain in place. Creating new preserves the source and selects the new environment only for the initiating workflow, including when another workflow is active at completion. This session-selection behavior is a demo default pending product decisions.

Use **Demo scenarios & inbox** to select an existing environment, first-time setup, or the M2 team-request preview. Controls can simulate preparation failure, hold accepted jobs, seed running/queued jobs, or finish the next job. Close this overlay before interacting with the underlying panel. Failure retains selections and offers retry, edit, and copying repair context to local Codex/Claude. M2 previews all-admin requests, preselected review and requester availability after explicit application.

First-time setup stays entirely in Cloud: select packs, review the new environment name, models, suggested GPU and storage costs, prepare in the background, then explicitly approve using the new environment. Standard Cloud remains usable through preparation or failure. Applying the first custom environment changes only the initiating workflow and preserves Standard Cloud for other workflows. The manager then supports updates to that newly created environment. No paid-tier gate is introduced. After application, selected RMBG/Acme fixture nodes appear in editor search and have insertion shortcuts. Other packs are manifest simulations.

All preparation, jobs, roles, notifications and environment changes are local simulations. There is no GPU execution, billing, upload, repository fetch, real email, production mutation or integrated repair. Refresh resets the demo; persistence across refresh or tab closure is not promised.
